### 🚀 Featured Projects

#### 🛒 [ClickKart](#)
A full-stack e-commerce web app built solo. Handles auth and product/order management end to end.
- HTML, CSS, JavaScript frontend
- Node.js, Express, MongoDB backend
- JWT authentication with bcrypt password hashing
- REST API endpoints for signup, signin, and CRUD operations
- Tested with Postman; backend confirmed working locally

#### 🎫 QueueLess Nigeria
A queue management and appointment booking platform for Nigerian organizations.
- Frontend rebuilt with React + Tailwind CSS (migrated from plain HTML/CSS/JS)
- Node.js/Express/MongoDB backend with a production-style structure (controllers, services, validators, sockets, jobs)
- Real-time queue updates via Socket.IO, JWT auth, Swagger API docs, Jest tests
- Custom "ticket-motif" design system (forest green/amber/paper palette)

#### 🚌 Beyond The Bus Stop (BTBS)
A transit navigation app built with a team as a TechyJaunt capstone project — backend lead.
- Shows routes, recommended bus, price, and a price confidence score
- Live trip-sharing: generates a shareable link so trusted contacts can track a live location on a map
- Real-time location updates via WebSockets/Socket.IO
- Deployed backend on Render; full technical documentation produced covering architecture, APIs, and confidence scoring
